How this works

Deribit price & greeks pulled from openclaw API every 5 minutes (fetch from this page; works directly via file:// and Squarespace since openclaw allows CORS). The "Last Deribit feed" stamp reflects the feed's own snapshot_at — so if openclaw's poller stalls you'll see the data's true age, not a wall-clock "now". Positions read from positions.json next to this file (embedded fallback when served where the file isn't reachable, e.g. Squarespace) — refreshed when you drop a new TigerEx CSV into current position/. AI analyses are computed client-side — no API key, no LLM call.

Quarterly fund cadence means positions only change on assignment / calendar swap / strike roll. When that happens, drop the new TigerEx CSV in current position/ and either ask Cowork "refresh CMFDH positions" or run refresh_positions.py in this folder.
